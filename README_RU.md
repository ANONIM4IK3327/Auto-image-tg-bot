# 🤖 Auto-Image Telegram Bot

> **Vibeproject**

> **[🇷🇺 Русская документация](README_RU.md)** | **[🇬🇧 English documentation](README.md)**

Автоматический Telegram-бот для генерации AI-изображений через распределённую сеть [Stable Horde](https://stablehorde.net/) и публикации их в группы или каналы по расписанию. Работает полностью на **Cloudflare Workers** — без сервера, на бесплатном тарифе.

- Добавлены функции для участников без привилегированных ролей: `/promptsuggest` с кнопками модерации (approve / rework / reject).
- Для участников доступен `img2txt` с настраиваемым кулдауном (по умолчанию: 1 час).

- 📐 **Умный выбор разрешения** — LLM выбирает оптимальное соотношение сторон
- 📦 **Батч-генерация** — от 1 до 10 изображений за раз

## 🏗️ Архитектура

```
Telegram Webhook
      │
      ▼
Cloudflare Worker (worker.js)
      │
      ├─► Upstash Redis  (конфиг, очередь, чёрный список)
      ├─► Stable Horde API  (генерация изображений)
      ├─► OpenRouter API  (LLM для промптов и подписей)
      └─► wsrv.nl  (наложение водяного знака)
```

Воркер запускается **двумя способами**:
1. **HTTP Webhook** — получает сообщения и команды из Telegram
2. **Cron-триггер** (`* * * * *`) — каждую минуту проверяет статус задач Horde и инициирует плановые публикации

## 🚀 Установка — Cloudflare (рекомендуется)

### Шаг 1 — Клонируй репозиторий

```bash
git clone https://github.com/your-username/auto-image-tg-bot.git
cd auto-image-tg-bot
```

### Шаг 2 — Установи Wrangler CLI

```bash
npm install -g wrangler
wrangler login
```

### Шаг 3 — Создай базу Upstash Redis

1. Перейди на [upstash.com](https://upstash.com) → создай бесплатную Redis БД
2. Скопируй **REST URL** и **REST Token** из дашборда

### Шаг 4 — Проверь `wrangler.toml`

Файл уже есть в репозитории. При желании измени `name`:

```toml
name = "autoimgtg"
main = "worker.js"
compatibility_date = "2024-12-01"

[triggers]
crons = ["* * * * *"]

[observability]
enabled = true
head_sampling_rate = 1
```

### Шаг 5 — Задай секреты

```bash
wrangler secret put TELEGRAM_BOT_TOKEN
# вставь токен бота

wrangler secret put UPSTASH_REDIS_REST_URL
# вставь REST URL из Upstash

wrangler secret put UPSTASH_REDIS_REST_TOKEN
# вставь токен Upstash

wrangler secret put HORDE_API_KEY
# вставь ключ Stable Horde (или пропусти — будет анонимный)

wrangler secret put OPENROUTER_API_KEY
# вставь ключ OpenRouter (или пропусти — LLM работать не будет)
```

### Шаг 6 — Задеплой

```bash
wrangler deploy
```

Получишь URL вида: `https://autoimgtg.your-subdomain.workers.dev`

### Шаг 7 — Зарегистрируй вебхук

Открой в браузере:

```
https://autoimgtg.your-subdomain.workers.dev/setup
```

Должен появиться ответ с `"ok": true`. Вебхук зарегистрирован.

### Шаг 8 — Запусти бота

Напиши `/start` своему боту в Telegram. **Первый пользователь**, отправивший любую команду, автоматически становится **admin**.

## 💻 Установка — Локально

> ⚠️ В локальном режиме используется dev-сервер Wrangler. Cron-триггер **не срабатывает автоматически** — его нужно вызывать вручную или через `wrangler dev --test-scheduled`.

### Требования

- Node.js 18+
- npm или yarn

### Шаги

```bash
# 1. Установи зависимости
npm install

# 2. Создай файл .dev.vars (локальные секреты — не добавляй в git!)
cat > .dev.vars << 'EOF'
TELEGRAM_BOT_TOKEN=твой_токен_бота
UPSTASH_REDIS_REST_URL=https://xxx.upstash.io
UPSTASH_REDIS_REST_TOKEN=твой_токен_upstash
HORDE_API_KEY=твой_ключ_horde
OPENROUTER_API_KEY=твой_ключ_openrouter
EOF

# 3. Запусти локальный dev-сервер
wrangler dev

# Воркер доступен на http://localhost:8787
```

> Чтобы Telegram смог достучаться до localhost, нужен туннель (например [ngrok](https://ngrok.com)):
> ```bash
> ngrok http 8787
> # Затем открой: https://your-ngrok-url.ngrok.io/setup
> ```

Чтобы **вручную запустить крон** (проверить Horde / опубликовать изображения):

```bash
curl "http://localhost:8787/__scheduled?cron=*+*+*+*+*"
```

## 📝 Синтаксис промптов (продвинутый)

В каждом сегменте промпта поддерживаются специальные блоки `{...}`:

| Синтаксис | Эффект |
|---|---|
| `{loraId:сила}` | Применить конкретную LoRA только для этой генерации |
| `{loraId:сила:clip}` | То же, с явным clip-весом |
| `{-loraId}` | Исключить глобальную LoRA для этой генерации |
| `{-llm}` или `{nollm}` | Отключить улучшение промпта через LLM |

**Инъекция инструкции** — оберни часть промпта в `[...]`, чтобы дать LLM конкретное указание:

```
cute anime girl [одень её в красную школьную форму, стоит под дождём]
```

**Несколько сегментов промпта** — разделяй через `;`. Каждый пост случайно выбирает один:

```
/addprompt фэнтезийный пейзаж ; киберпанк-город ; аниме-девушка {12345:0.8}
```

## 💧 Водяной знак

- Отправь боту **прозрачный PNG** как документ с командой `/setwatermark`
- Водяной знак накладывается через [wsrv.nl](https://wsrv.nl) (бесплатный CDN-прокси изображений)
- Позиции: `random`, `corner`, `northwest`, `northeast`, `southwest`, `southeast`, `center`
- Если Horde возвращает base64 (не URL), водяной знак автоматически пропускается

## ❓ Частые вопросы

**В: Нужна ли мне видеокарта?**
Нет. Stable Horde — это распределённая сеть GPU-воркеров от сообщества. Генерация бесплатная, но может занимать 1–5 минут.

**В: Что если изображения цензурируются?**
Бот автоматически добавляет проблемный воркер в чёрный список и делает до 3 попыток с другими воркерами.

**В: Можно ли без OpenRouter?**
Да. Без ключа OpenRouter промпты отправляются в Horde как есть (без LLM-расширения, без AI-подписей, случайное разрешение).

**В: Как использовать несколько промптов?**
Используй `/addprompt` несколько раз. Каждый пост выбирает случайный сегмент. Можно задать все сразу через `/setprompt тема1 ; тема2 ; тема3`.

**В: Какой лимит у бесплатного Cloudflare Workers?**
100 000 запросов в день на бесплатном тарифе. Для бота, работающего каждую минуту, этого более чем достаточно.

**В: Почему крон срабатывает раз в минуту?**
Каждую минуту воркер: (1) проверяет завершённые задачи Horde и доставляет готовые изображения, (2) при необходимости запускает новую генерацию по расписанию. Логика интервала хранится в Redis — реальные публикации происходят не чаще, чем задано в `/setinterval`.
